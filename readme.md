# 🖨️ Driver Printer Auto Cutter Thermal 80mm Universal

Universal driver collection for 80mm thermal receipt printers with **Auto Cutter** support.

This repository provides drivers that are compatible with many generic/OEM 80mm thermal printers, including printers sold under different brands. These drivers are useful when the original driver is unavailable or when the auto cutter feature does not work properly.

## ✨ Features

- ✅ Supports 80mm thermal receipt printers
- ✂️ Auto Cutter support
- 🖥️ Windows compatible
- 🔄 Compatible with many ESC/POS printers
- 📦 Easy installation

## 📁 Contents

This repository may include:

- XPrinter Driver
- ESC/POS Driver
- Universal Driver
- Installation Guide
- Additional utilities (if available)

## 🚀 Installation

1. Download the latest release.
2. Extract the ZIP file.
3. Run the installer.
4. Connect your printer.
5. Select the correct com/usb port.
6. Test print to verify the Auto Cutter works.
